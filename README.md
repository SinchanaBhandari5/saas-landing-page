# Launchly – SaaS Landing Page with Sign-Up Workflow

## Introduction
Launchly is a responsive SaaS landing page designed to introduce a software product and allow users to sign up easily. It provides a simple and attractive interface with features, pricing details, and a registration form.

## Features
- Attractive landing page design.
- Responsive layout for different screen sizes.
- Features and pricing sections.
- User sign-up form.
- Form validation.
- Duplicate email checking.
- Thank-you message after successful registration.
- Stores registration details using Local Storage.

## Technologies Used
- HTML5 – Structure of the webpage.
- CSS3 – Styling and responsive design.
- JavaScript – Form validation and functionality.
- Local Storage – Storing registration details in the browser.

## Project Structure
```text
Launchly/
│
├── index.html
├── style.css
└── script.js
```

## How to Run
1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.
4. Explore the landing page and test the sign-up form.

## Conclusion
Launchly provides a simple demonstration of a SaaS landing page and sign-up workflow. This project helped in understanding webpage design, responsive layouts, JavaScript form validation, and browser-based data storage.
